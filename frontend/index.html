🔄 Plex sync

Pull new watch history from Plex and recompute taste vectors.

🔁 Re-attribute history

Re-pulls Plex's play history and fixes per-user attribution on existing rows. Run after a new user logs in via Plex OAuth so their pre-existing plays move from admin to their account. Idempotent.
Note: Plex only retains a limited window of play events. Plays older than that retention horizon stay attributed to admin — that's expected, not a failure. Going forward, every new sync attributes correctly per Plex account from the start.

🧹 Cleanup orphans

Delete watch_history rows pointing to media that's no longer in any Plex library. Spotify entries are preserved. Aborts safely if any library section can't be read. Destructive.
