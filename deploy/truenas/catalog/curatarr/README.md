# Curatarr

[Curatarr](https://github.com/Randomname653/Curatarr) is a self-hosted AI curator for Plex or Jellyfin and the arr stack: it learns the household's taste from the watch history, recommends from the library and beyond, and proposes what to delete through Radarr, Sonarr and Lidarr. It needs an [Ollama](https://ollama.com) server for its curator model.
